Bem-vindo ao meu projeto de CRM Comercial! Este é um sistema responsivo criado por mim, Gabriel dos Santos Gomes, para uso real em sua empresa de trabalho. Esta versão não contém a logo e os dados reais do sistema que a empresa utiliza para fins de segurança, utilizando mock data (por meio de json) para a simulação de API Rest.

<h1>Funcionalidades</h1>
Criar, deletar e consultar Leads de clientes;
Avançar Leads de posição através das colunas;
Consultar clientes;
Consultar datas dos compromissos por tido (ex.: reunião);
Alterar entre modo claro e modo escuro

<h1>Tecnologias Utilizadas</h1>
NextJS, React, TypeScript, Taiwlind CSS
