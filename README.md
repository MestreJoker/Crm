## 🚀 Tecnologias Utilizadas

O sistema foi construído utilizando pilares modernos do ecossistema front-end:

* **Framework:** [Next.js](https://nextjs.org/) (App Router)
* **Biblioteca UI:** [React](https://react.dev/)
* **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
* **Estilização:** [Tailwind CSS](https://tailwindcss.com/)

---

## 💡 Funcionalidades Principais

* **Kanban de Leads (CRM):** Crie, consulte, delete e avance leads de clientes pelas colunas do funil de vendas (Contato, Reunião, Proposta, etc.)[cite: 11].
* **Base de Clientes:** Listagem centralizada com dados cadastrais e histórico de interações[cite: 12].
* **Agenda de Atividades:** Acompanhamento de compromissos e reuniões organizadas por tipo e data em formato de calendário interativo[cite: 13].
* **Modo Escuro / Claro:** Alternância fluida entre temas para melhor experiência visual do usuário[cite: 14].
